# 架构说明

## 核心链路

    1688/授权ERP -> SourceProductProvider -> 应用服务
    腾讯文档 <-> MappingStore <-> 应用服务
    拼多多/授权ERP <- MarketplaceAdapter <- 应用服务
    企业微信/QQ/邮件 <- AlertNotifier <- 应用服务

application 不直接依赖任何平台 SDK。外部 API、认证、限流和重试全部放在 infrastructure 中。

## 自动化边界

| 动作 | 默认策略 |
| --- | --- |
| 同步货源库存、采购价 | 自动 |
| 生成商品上架草稿 | 自动 |
| 首次上架、改价超过阈值 | 人工确认 |
| 缺货 SKU 停售 | 自动预警，按规则执行 |
| 1688 采购付款 | 人工确认 |
| 退款、平台违规 | 人工处理并保留审计记录 |

## 预警等级

| 等级 | 示例 | 建议动作 |
| --- | --- | --- |
| P0 | 货源不可售、平台授权失效 | 立即暂停相关商品 |
| P1 | 缺货、利润跌破阈值 | 停售 SKU 或进入调价审核 |
| P2 | 发货变慢、转化下降 | 通知运营复核 |
| P3 | 素材或映射字段缺失 | 进入待处理队列 |
